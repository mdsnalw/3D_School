# 数字孪生校园 · Digital Twin Campus

基于 **CesiumJS** 构建的校园三维数字孪生可视化单页应用。建筑体量依据实景立面照片与航拍俯视图程序化建模，整体采用**深色科技风 + 完全矢量**的视觉体系 —— **不加载任何卫星影像或实景地图瓦片**，周边城市肌理全部由代码绘制。

整个项目就是**一个 HTML 文件**，无需构建、无需安装依赖。

![校园全景](docs/preview.png)

## 主要功能

### 三维场景建模

场景全部由代码生成，不依赖外部模型文件：

| 要素 | 说明 |
|---|---|
| 建筑体块 | 6 栋建筑，用多边形拉伸（`extrudedHeight`）生成体量，立面贴程序化生成的横向窗带 |
| 400 米标准跑道 | 带孔多边形挖空内场，含分道线、中点圈、球门区 |
| 足球场 | 标准场地白线 + 中圈 + 罚球区 |
| 室外球场 | 5 片篮球 / 网球场地，含边线、中线、中圈 |
| 绿化植被 | 树木（圆柱树干 + 双层椭球树冠）成排布置 |
| 周边城市肌理 | 554 个程序化生成的低伏体块 + 街区网格 + 市政道路，**纯矢量、无实拍素材** |

### 交互功能

- **点击建筑** —— 高亮选中、弹出信息卡（层数 / 面积 / 容纳人数）、相机自动聚焦
- **视角预设** —— 全景、教学区、运动场、校门、自动巡游（绕校园环飞）
- **场景图层开关** —— 建筑体块、运动场地、绿化植被、设施标签、人流热力，可独立显隐
- **昼夜切换** —— 白天 / 夜间模式；夜间建筑窗带点亮为暖黄，模拟教室亮灯
- **环境配色** —— 「墨绿」「深空」两套深色科技风配色，一键切换
- **实时数据看板** —— 建筑数量、占地面积、在校人数、绿化率等指标动态展示

### 视觉体系

- **深墨绿 / 近黑底色** + 白色描边的矢量线框质感
- **暗底亮物** 对比：校园为亮色主体，周边城市压暗，形成视觉聚焦
- **信息卡片** 采用深色玻璃拟态（`backdrop-filter: blur`），对齐深色科技风参考图

### 稳定性设计

- **环境自检** —— 启动时检测 WebGL 支持与显卡渲染模式，异常时给出明确提示
- **渲染健康检查** —— 轮询采样绘制命令，长时间无输出才报警（避免加载期误报）
- **无外部瓦片依赖** —— 不请求任何地图服务，断网也能完整显示，不存在底图加载失败导致的空白
- **CDN 双源兜底** —— Cesium 主库走 jsdelivr，失败自动切 unpkg

## 快速开始

### 方式一：一键启动（Windows）

双击 **`启动校园.bat`**。脚本会自动定位 Python、启动本地服务并打开浏览器。

### 方式二：手动启动

```bash
# 在本目录下执行
python -m http.server 8899 --bind 127.0.0.1
```

然后浏览器访问 <http://127.0.0.1:8899/index.html>

> **⚠️ 不要直接双击 `index.html`**
>
> 浏览器在 `file://` 协议下会拦截 Cesium 依赖的 Web Worker 与贴图资源，导致整个三维场景无法渲染 —— 表现为只有背景星空和文字标签，建筑和地面全部消失。
>
> 这是浏览器的安全策略，不是代码问题。**必须通过 HTTP 服务访问。**

## 技术实现

### 技术栈

- **CesiumJS 1.119** —— 三维地理引擎
- **原生 JavaScript** —— 无框架、无构建步骤
- **纯矢量渲染** —— 不使用任何地图瓦片服务（无高德 / 天地图 / ion）

### 关键设计

**局部平面坐标系建模**

为了便于按参考图布局，整个校园建立在一个以米为单位的局部平面坐标系上，再统一转换为经纬度：

```js
const ORIGIN = { lon: 118.0894, lat: 24.4798 };  // 校园基准点
const M_PER_DEG_LAT = 111320;   // 每度纬度对应的米数
const M_PER_DEG_LON = 101313;   // 该纬度下每度经度对应的米数

function toCarto(x, y, h = 0) {
  return Cesium.Cartesian3.fromDegrees(
    ORIGIN.lon + x / M_PER_DEG_LON,
    ORIGIN.lat + y / M_PER_DEG_LAT,
    h
  );
}
```

这样建模时可以直接写"教学楼在中心点西侧 95 米"，无需处理经纬度。

**跑道几何**

400 米标准跑道是胶囊形（两个半圆 + 直道），用带孔多边形实现中间挖空：

```js
new Cesium.PolygonHierarchy(outerRing, [new Cesium.PolygonHierarchy(innerRing)])
```

**立面窗带为什么用几何体而不用贴图**

Cesium 对拉伸多边形（`extrudedHeight`）的墙面 UV 是按**整个周长归一化**的，实测一栋 130 米的楼贴一张 512px 纹理，整个立面只会显示出纹理极窄的一条，看起来就是一片纯色。

因此窗带改为**显式几何**：每层在建筑四面外侧各贴一条「薄板」（约 1 米厚 × 130 米长 × 1.9 米高），位置和高度完全精确可控，远看也清晰。

```js
// 南面窗带：沿 x 铺满，沿 y 外挑 0.75 米，两端内缩 1.4 米避免转角穿插
rectDegrees(x0 + IN, y0 - OUT, x1 - IN, y0, 0)
```

**`rectDegrees` 的坑**

`rectDegrees()` 返回的**已经是 `Cartesian3[]`**，直接传给 `PolygonHierarchy` 即可：

```js
// ✅ 正确
new Cesium.PolygonHierarchy(rectDegrees(x0, y0, x1, y1, 0))

// ❌ 错误：二次转换会产生退化多边形（2 个 null 顶点，什么都不显示）
new Cesium.PolygonHierarchy(
  Cesium.Cartesian3.fromDegreesArray(rectDegrees(x0, y0, x1, y1, 0)))
```

**环境配色的初始化**

`applyTheme()` 必须在场景构建完成后**主动调用一次**，否则 `globe.baseColor` 会保持 Cesium 默认的深蓝（`#000080`），与深色城市体块几乎同色 —— 表现为"周边城市肌理看不见"。

**无头验证**

用 Playwright + 系统 Chrome 做无头渲染自检，判断指标：

| 指标 | 正常值 | 异常含义 |
|---|---|---|
| `scene.frameState.commandList.length` | 几十条 | `0~8` 说明实体没渲染 |
| `entities.values.length` | 1500+ | 过少说明构建函数没跑完 |
| `imageryLayers.length` | `0` | 非 0 说明还在加载地图瓦片 |
